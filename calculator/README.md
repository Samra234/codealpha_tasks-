
# Modern Calculator

A simple, responsive calculator built using HTML, CSS, and JavaScript. It supports mouse clicks and keyboard input with a modern dark-themed design.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division.
- Percentage calculations.
- Decimal number support.
- Clear and delete functions.
- Keyboard support for faster calculations.
- Interactive button hover and click effects.
- Responsive design for desktop and mobile devices.
- Division-by-zero error handling.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start calculating!

No additional libraries or installations are required.

## Keyboard Shortcuts

| Key | Action |
|---|---|
| 0–9 | Enter numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| . | Decimal point |
| Enter | Calculate result |
| = | Calculate result |
| Backspace | Delete last digit |
| Escape | Clear calculator |
| % | Percentage |

## Deployment

You can deploy this project for free using Netlify or GitHub Pages.

### Netlify

1. Push your project files to GitHub.
2. Log in to Netlify.
3. Select **Add new project** and import your GitHub repository.
4. Leave the build command and publish directory empty for this plain HTML/CSS/JavaScript project, unless your deployment setup requires otherwise.
5. Deploy the website.
